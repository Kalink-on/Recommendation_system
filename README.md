# Filmore
## Описание приложения
Filmore — это система рекомендаций фильмов, которая анализирует ваши предпочтения и предлагает персонализированные рекомендации. Программа позволяет получать персональные рекомендации на основе ваших предпочтений и искать топы фильмов по жанрам, годам и оценкам.

## Начало работы
#### Требования к системе:
1.	ОС: Windows, macOS или Linux
2.	Python 3.8 или выше
3.	Библиотеки: pandas, numpy, matplotlib, scikit-learn, scipy
4.	8+ ГБ оперативной памяти (рекомендуется)
5.	2+ ГБ свободного места на диске

#### Установка
1.	Установите Python с официального сайта по ссылке: https://www.python.org/downloads/
2.	Рекомендуется установить PyCharm по ссылке: https://www.python.org/downloads/
3.	Загрузите файлы приложения в отдельную папку по ссылке: https://github.com/Kalink-on/Recommendation_system 
4.	Скачайте датасет MovieLens c официального сайта: https://grouplens.org/datasets/movielens/ (раздел recommended for education and development, ml-latest.zip (size: 335 MB) для расширенных рекомендаций или ml-latest-small.zip (size: 1 MB) для базовых рекомендаций) и поместите его в папку с проектом
5.	Установите необходимые зависимости при помощи команды в терминале: `pip install -r requirements.txt`

Команда для запуска приложения: `python gui.py`
